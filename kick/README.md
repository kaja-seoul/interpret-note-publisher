# 깨우기 파일

GitHub 예약 실행(cron)이 거의 오지 않아서(10/28 확인: 36시간 동안 6번) 만든 길이다.
`slot.txt` 첫 줄을 바꿔 main에 올리면 `publish`가 바로 돈다.

| 첫 줄 | 하는 일 |
|---|---|
| `live auto <시각> <누가>` | 예약 실행과 같음. 깬 시각으로 슬롯을 정하고(슬롯 55분 전 ~ 90분 뒤), '승인' 행만 실제로 올린다. 창 밖이면 그냥 끝. |
| `dry <08:07·21:37·auto> <시각> <누가>` | 같은 길로 드라이런만(게시 안 함). 시험용. |

- 쓰는 곳: Claude 예약 작업 '스레드 게시기 깨우기' (KST 07:20·07:50·08:15, 20:50·21:20·21:45). 확인 작업은 08:32·22:02.
- 여러 번 깨워도 한 슬롯에 한 번만 올라간다: 실행은 차례로 돌고(concurrency 'publish'), '게시됨'·게시 링크가 있는 행은 고르지 않고, 계정 최근 글과 본문이 같으면 다시 올리지 않는다.
- 예약 cron은 예비로 그대로 둔다.
